The new [testing/weave] package systematically explores the goroutine
interleavings of a concurrent unit test, so a single test can deterministically
surface schedule-dependent bugs (lost updates, deadlocks, broken invariants) and
report a reproducible seed. Channel and mutex operations are always scheduling
points; building with the `-weave` flag additionally makes ordinary memory
accesses scheduling points so data races on plain variables can be explored.
